Hack K-State 2025

In October of 2025 I competed with two other CS students in the Fall Hackathon at K-State. We created a web based racing game that utilized AI to create opponents that would race against the player on unique, player created tracks. The game was created using javascript.

The Game

We created an AI model using PyTorch that took a JSON of player input and car data based on raycasts to nearby objects to determine the best next move for the AI to make. The AI was trained on a dataset of player input and car data that we collected from playtesting the game. The player was able to create their own tracks using a simple track editor that we created. The game was played in a web browser while the player used a controller or arrow keys for control.
